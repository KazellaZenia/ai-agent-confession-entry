## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/conf-out node main.ts
cat /tmp/conf-out/entry.txt
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` and
fails fast if the line breaks the gate (empty, over 200 characters, or more
than one line).
